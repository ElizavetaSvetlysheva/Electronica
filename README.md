# Electronica
Запуск проекта Electronica производится через клавишу F5 или верхнюю консоль кнопкой запуска

Примечания:
- Дубликат SKU пропускается, добавляется ошибка «Артикул товара уже существует».
- Кодировка файла: UTF-8 (с BOM или без); если файл не UTF-8, читается как Windows-1251.
- Путь: абсолютный (`C:\data\products.csv`, `/home/user/products.csv`) или относительно wwwroot (`/csv/sample_products.csv`).
- Дополнительно: итоговая сумма и количество, поиск по названию/артикулу/бренду, фильтр по категории, сортировка и кнопка «Очистить список» на странице товаров.
